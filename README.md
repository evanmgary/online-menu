Online Menu & Ordering App

A full-stack web application for browsing a menu, placing orders, and managing menu items through an admin interface. This project was built to practice CRUD operations, database integration, and full-stack data flow.

Overview

This application simulates a simple restaurant ordering system with two main interfaces:

User interface – browse menu items, add to cart, and place orders
Admin interface – create, update, and delete menu items

Orders and menu data are stored in a PostgreSQL database and accessed through Prisma.

Features
Browse categorized menu items
Add/remove items from a cart
Submit orders
View incoming orders (kitchen/order screen)
Admin panel for:
Creating new menu items
Updating existing items
Deleting items
Option-based pricing adjustments
Real-time-ish order updates via polling
